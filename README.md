# Workforce SQL Insights

A SQL-based workforce analytics project exploring headcount, salary distributions, hiring trends, employee tenure, and workforce turnover.

## Technology Stack

- [DuckDB](https://duckdb.org/) for local, serverless SQL execution
- Python 3.10+ for reproducible synthetic data generation and automated checks
- pytest for validating analytical metrics

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows, activate the environment with `.venv\Scripts\activate`.
